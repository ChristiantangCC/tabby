# Changelog

## 0.2.3

- Switching to a full-screen window now also works when the same app has a window on your current Space (like normal Chrome next to a full-screen Chrome stream). Tabby briefly takes the window out of full screen and puts it back.
- From inside a full-screen app, windows on the desktop behind it (like Claude next to the full-screen stream) now show up in the switcher.
- Windows an app still reports after closing them no longer show up as empty tiles.
- Full-screen windows of apps like Chrome are found more reliably.

## 0.2.2

- Windows are listed in the order you last used them, across all screens, however you switched (Tabby, a click, the Dock or ⌘Tab).
- Switching to a full-screen window now moves to its Space and brings it forward, instead of just selecting it.

## 0.2.1

- Full-screen windows (the green button, like a maximised stream) now show up in the switcher, and switching to one jumps to its Space.

## 0.2.0

- The selected window's real position on screen is outlined and left undimmed while you tab. Turn it off in Settings → Layout.

## 0.1.0

The first release.

- Hold ⌥ and tap Tab to see every window as a live thumbnail; let go to switch.
- Six layouts: Thumbnails, Cover Flow, Deck, Orbit, Spotlight and Time Machine.
- Light, dark or system theme, glass/solid/frameless surface, accent colour, size and animation speed.
- Rebind the shortcut in Settings.
- Tabby checks GitHub for new releases and tells you when one is out.
